# 🎨 Color Picker

A simple Chrome extension that lets you pick a color and instantly get its HEX and RGB values.

## ✨ Features

- 🎨 Pick any color using the built-in color picker
- 🔢 Get the HEX value of the selected color
- 📋 Copy the HEX value to your clipboard
- 🔄 Convert HEX values to RGB
- 🌈 Display the RGB value
- 📋 Copy the RGB value to your clipboard
- ✅ Shows "Copied" feedback after copying

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Chrome Extension Manifest V3

## 🚀 Installation
Since this extension is not published on the Chrome Web Store, you can install it using Chrome's Developer Mode.
1. Download the project
Click:
Code → Download ZIP
on this GitHub repository.
2. Extract the ZIP
Extract the downloaded ZIP file to a location on your computer.
3. Open Chrome Extensions
Open Chrome and go to:
chrome://extensions

4. Enable Developer Mode
Turn on Developer mode in the top-right corner.
5. Load the extension
Click:
Load unpacked
Then select the extracted Color-Picker folder.
6. Pin the extension
Click the 🧩 Extensions icon in Chrome and pin Color Picker for easy access.

## 🎯 How to Use
1. Open the Color Picker extension.
2. Select any color.
3. The HEX and RGB values will be displayed automatically.
4. Click Copy next to HEX or RGB to copy the value.
5. The button will temporarily change to Copied as confirmation.
